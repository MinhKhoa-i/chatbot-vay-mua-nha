# Danh sách test case ban đầu

Danh sách kiểm thử . Phạm vi gồm trang chủ, giao diện chat, form nhập thông tin khách, API backend, hàm tính khoản vay, nội dung trả lời và dữ liệu cá nhân. Số liệu mong đợi lấy từ `backend/finance/calculator.py`; API theo `docs/api.md`.

## 1. Cách chạy

| Chế độ     | Cách bật                                                                                                                           | Dùng để kiểm                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------- |
| Mock          | `frontend/.env`: `VITE_USE_MOCK=true` (mặc định), chỉ cần `npm run dev`                                                   | Giao diện, form, luồng thao tác khi chưa có backend       |
| Backend thật | `npm run dev:backend` (hoặc `VITE_USE_MOCK=false`, `VITE_API_URL=http://localhost:8000` rồi `npm run dev`), chạy thêm `uvicorn app.main:app --port 8000` trong `backend/` | Hợp đồng API, số liệu từ `calculator.py`, xử lý lỗi |
| Tự động    | `cd backend && python -m pytest`                                                                                                   | Các ca có ghi tên test ở cột "Tự động"                 |

Quy ước:

- **Mức độ:** Cao = sai thì chặn merge; TB = sửa trong tuần; Thấp = ghi nhận.
- **Kết quả:** `Đạt`, `Lỗi (#issue)`, hoặc `Chưa chạy`. Lần chạy đầu ngày 08/11/2026 trên Chrome, máy Windows.
- Tiền viết theo cách giao diện hiển thị (`13.017.349 đ`); lãi suất %/năm.
